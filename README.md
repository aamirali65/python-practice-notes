# PythonDays

Day-by-day Python learning notes, one file per topic — the order roughly follows how the language is usually taught.

| File | Topic |
|---|---|
| `Variables.py` | Variables and assignment |
| `DataTypes.py` | Built-in data types |
| `Operator.py` | Operators and expressions |
| `FlowControl.py` | `if`/`elif`/`else` |
| `Loops.py` | `for` and `while` loops |
| `Lists.py` | Lists and their operations |
| `Functions.py` | Defining and calling functions |
| `Modules.py` | Importing and using modules |
| `Object.py` | Classes and objects |
| `Inheritance.py` | Inheritance and subclassing |
| `Class.py` | Class structure in more depth |

## Running

Each file is self-contained and prints its results:

```bash
python Variables.py
```

## Notes

Personal study notes rather than a package — the point is the examples, which are short and meant to be read alongside the source.
